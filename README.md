# K and K Knight Podcast WordPress Template

K and K Knight Podcast 向けの WordPress デザインテンプレート制作リポジトリです。

このリポジトリでは、実装前の要件、基本設計、デザイン指針、開発ルール、セキュリティ方針、Claude Code 用設定、作業ログ、プロンプト記録を管理します。

## 前提

- 対象サイト: https://podcast.kk-k.net/
- 番組概要: `kk-knight-lp-research.md`
- 参考ビジュアル: `image/ChatGPT Image 2026年4月30日 22_26_10.png`
- 画像プロンプト: `image/image_pronpt.txt`
- WordPress プラグイン: Blubrry PowerPress を利用し、PowerPress Player または `[powerpress]` ショートコードをテーマ内で扱う
