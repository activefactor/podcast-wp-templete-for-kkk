# 要件定義書

作成日: 2026-04-30  
対象: K and K Knight Podcast WordPress デザインテンプレート

## 1. 目的

K and K Knight Podcast の既存 WordPress サイトを、Podcast 番組らしい視聴導線、番組理解、最新回への到達性を備えたデザインテンプレートに刷新する。

実装は Claude Code で行う想定とし、本書では開発前に必要な要件を定義する。

## 2. 参照情報

- 公式サイト: https://podcast.kk-k.net/
- 公式 About: https://podcast.kk-k.net/sample-page/
- 調査メモ: `kk-knight-lp-research.md`
- 参考ビジュアル: `image/ChatGPT Image 2026年4月30日 22_26_10.png`
- PowerPress: https://wordpress.org/plugins/powerpress/

公式 About では、デジタルハリウッド講師である K&K のコンビによる Podcast 番組で、Web、ガジェット、教育などを主なテーマに毎週木曜日に定期配信中と説明されている。

## 3. 制作範囲

### 対象範囲

- WordPress テーマテンプレートの設計
- トップページ LP
- 投稿一覧、カテゴリ一覧、アーカイブ一覧
- Podcast 個別回ページ
- About/番組紹介ページ
- ホスト紹介セクション
- 視聴・購読導線
- Blubrry PowerPress プレイヤー表示
- レスポンシブ対応
- アクセシビリティ基本対応
- セキュリティ基本対応

### 対象外

- WordPress 本体の構築、サーバー移行
- PowerPress のアカウント契約やメディアホスティング設定
- 実在プラットフォームロゴの新規制作
- ホスト本人の写真撮影、肖像素材制作
- Podcast 配信先の管理画面操作

## 4. ユーザー像

- Web制作、デザイン、フロントエンドに関心のある人
- 教育ICT、AI活用、授業づくりに関心のある教員、講師、学生
- ガジェット、Apple製品、カメラ、文房具などが好きな人
- 堅すぎない会話で制作や教育の現場感を追いたい人

## 5. 機能要件

### 5.1 トップページ

- 番組名「K and K Knight Podcast」をファーストビューで明確に表示する。
- 番組の説明コピーを表示する。
- 最新回を目立たせる。
- 最新回の PowerPress プレイヤーを表示できる設計にする。
- エピソード一覧への導線を置く。
- 視聴プラットフォームへの導線を置く。
- Topic、Hosts、Listen のセクションがファーストビュー下に続くことが分かる構成にする。

### 5.2 エピソード一覧

- 投稿を新着順に表示する。
- タイトル、日付、カテゴリ、再生時間、抜粋を表示する。
- カテゴリ絞り込みに対応する。
- ページネーションを表示する。
- カード単位でクリックしやすくする。

### 5.3 個別回ページ

- タイトル、公開日、カテゴリ、本文、PowerPress プレイヤーを表示する。
- `[powerpress]` ショートコードまたは PowerPress Player ブロックの表示を尊重する。
- 本文内のリンク、参照URL、コメント欄を読みやすく表示する。
- 前後のエピソード導線を表示する。

### 5.4 About/番組紹介

- 番組概要を表示する。
- 取り扱うテーマを表示する。
- ホスト2名の紹介を表示する。
- 肖像写真が未確定の場合は、抽象アイコンまたはイニシャル表現を使う。

### 5.5 視聴・購読導線

- Apple Podcasts、Spotify、Google Podcasts 相当の導線候補を持てる設計にする。
- 正式URLが未確定のものは設定値化し、空の場合は非表示にする。
- RSS フィード導線を表示できるようにする。

### 5.6 PowerPress 連携

- PowerPress Player ブロックを利用できるスタイルにする。
- ショートコード `[powerpress]` によるプレイヤー表示を想定する。
- カスタムテンプレート内で表示する場合は `do_shortcode('[powerpress]')` を検討する。
- PowerPress の出力 HTML を過剰に上書きしない。
- PowerPress が無効の場合は、プレイヤー領域に管理者向けの確認メッセージを表示できる設計にする。

## 6. 非機能要件

### 表示速度

- ファーストビューの画像は WebP/AVIF を優先する。
- CSS と JS は必要最小限にする。
- アイコンはライブラリまたは軽量 SVG を使う。
- WordPress の不要なクエリを避ける。

### レスポンシブ

- 対応幅: 360px 以上のスマートフォン、768px 以上のタブレット、1024px 以上のデスクトップ。
- Hero、最新回、カードグリッド、ナビゲーションが崩れない。
- ボタンとプレイヤーはスマートフォンでも押しやすくする。

### アクセシビリティ

- キーボード操作に対応する。
- フォーカスリングを表示する。
- 色だけで状態を伝えない。
- コントラスト比を確保する。
- 画像には代替テキストを付ける。

### 保守性

- テンプレートパーツ化する。
- 文章、リンク、テーマカラーは変更しやすくする。
- PowerPress 連携部分は局所化する。
- CSS は設計トークンを使い、色や余白の重複を避ける。

## 7. 制約

- 既存 WordPress の投稿データを前提にする。
- エピソードは投稿として扱う。
- PowerPress は 1投稿1メディアを基本にする。
- 実在人物の顔写真風イラストを勝手に作らない。
- プラットフォームロゴは公式利用規約を確認してから使う。

## 8. 未決事項

- Spotify の正式URL
- RSS フィードの正式URL
- 番組アートワークの正式素材と利用可否
- ホストプロフィールの最新表記
- 実装対象の WordPress/PHP バージョン
- 既存テーマからの移行範囲
- コメント欄を継続表示するか

## 9. 受け入れ条件

- トップページで番組内容と最新回がすぐ分かる。
- PowerPress プレイヤーがトップページまたは個別回で正常に表示される。
- スマートフォン、タブレット、デスクトップで主要導線が崩れない。
- Lighthouse の Accessibility が 90 以上を目標にできる構造になっている。
- テーマ有効化時に PHP エラーが出ない。
- 未設定の外部リンクが空リンクとして表示されない。
