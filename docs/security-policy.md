# セキュリティポリシー

作成日: 2026-04-30

## 1. 目的

K and K Knight Podcast の WordPress テーマ開発において、Podcast 配信、管理画面、外部リンク、プラグイン連携に関する基本的な安全性を確保する。

## 2. 対象

- WordPress テーマ
- テーマ内テンプレート
- CSS/JavaScript
- PowerPress 連携箇所
- 外部視聴リンク
- ドキュメントと設定ファイル

## 3. 基本原則

- 秘密情報をリポジトリに入れない。
- WordPress 標準APIを使う。
- 出力はエスケープする。
- 入力はサニタイズする。
- 外部リンクは安全属性を付ける。
- プラグインの更新を前提にする。

## 4. 禁止事項

- `.env`、APIキー、認証情報、FTP情報、管理者パスワードをコミットしない。
- テーマ内に外部スクリプトを無断で直読みしない。
- `eval()` を使わない。
- SQL を文字列連結で組み立てない。
- PowerPress の内部データ構造に依存した非公式実装をしない。
- 管理者以外が保存できる入力値を未検証で保存しない。

## 5. WordPress セキュリティ

### 出力エスケープ

- テキスト: `esc_html()`
- URL: `esc_url()`
- 属性: `esc_attr()`
- HTML許可付き本文: `wp_kses_post()`

### 入力サニタイズ

- テキスト: `sanitize_text_field()`
- URL: `esc_url_raw()`
- HTML制限付き: `wp_kses_post()`

### 権限確認

- 管理画面保存処理では `current_user_can()` を使う。
- nonce を作成、検証する。

## 6. PowerPress セキュリティ

- PowerPress は公式配布元からインストールする。
- 本番では常に更新状況を確認する。
- テーマ側で音声ファイルURLを直接保存しない。
- プレイヤー表示は PowerPress のショートコードまたはブロックに委ねる。
- プレイヤーが表示されない場合はテーマ競合、プラグイン競合、RSS妥当性を確認する。

## 7. 外部リンク

外部視聴プラットフォームへのリンクは以下を付ける。

```html
rel="noopener noreferrer"
target="_blank"
```

正式URLが未確認の場合は表示しない。

## 8. ファイル管理

コミット禁止:

- `.env`
- `.env.*`
- `wp-config.php`
- `secrets/`
- `node_modules/`
- `vendor/`
- WordPress のアップロード実体
- DB dump

## 9. Claude Code 利用時の注意

- 秘密情報を含むファイルを読ませない。
- `.claude/settings.json` で `.env` などの読み取りを拒否する。
- 破壊的なコマンドは人間が確認する。
- 実装前に関連ドキュメントを読む。

## 10. 脆弱性対応

脆弱性を発見した場合:

1. 再現条件を記録する。
2. 影響範囲を確認する。
3. 秘密情報をログやIssueに書かない。
4. 修正ブランチを作る。
5. 修正後に確認結果を `docs/development-log.md` に残す。
